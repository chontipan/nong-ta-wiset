# โมเดลขยะไทย AlphaTrash

โมเดลแบบ Teachable Machine (MobileNetV2 + ชั้นจำแนก 100 หน่วย) ฝึกจากภาพ train+val ของ
[AlphaTrash dataset](https://github.com/Patipol-BKK/alphatrash-dataset) (MIT) 4,842 ภาพ
และภาพพื้นหลังที่ไม่ใช่ขยะ 551 ภาพ เปิดใช้ได้จากปุ่ม "ใช้โมเดลขยะไทย AlphaTrash" ในหน้าสอน AI
หรือลิงก์ `?model=./models/alphatrash/`

| หมวด | ถังในแอป |
| --- | --- |
| recyclable: พลาสติก | รีไซเคิล |
| recyclable: กระป๋องโลหะ | รีไซเคิล |
| recyclable: กระดาษ / กล่อง | รีไซเคิล |
| general: เศษอาหาร (ขยะอินทรีย์) | ทั่วไป |
| general: ขยะทั่วไป | ทั่วไป |
| background | ไม่มีขยะ |

ผลบนชุด test ของ AlphaTrash (849 ภาพ): แยก 5 หมวดถูก 96.0% เลือกถังถูก 97.2%
(96.0% เมื่อใช้เกณฑ์มั่นใจ 0.75 ของแอป) ทักผิดบนภาพที่ไม่ใช่ขยะ 2 จาก 430 ภาพ

ข้อควรรู้: ภาพฝึกถ่ายในกล่องพื้นขาวด้วยกล้องตัวเดียว ถ้ากล้องหรือฉากหลังของตู้ต่างไปมาก
ความแม่นยำจะลดลง ไม่มีขยะอันตรายและไม่แยกขวดพลาสติกออกจากพลาสติกอื่น (พลาสติกทุกชนิดไปถังรีไซเคิล)
ฝึกใหม่ได้ด้วย `tools/eval-alphatrash/train-tm.js`
