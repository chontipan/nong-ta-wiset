# เทรนโมเดลแยกขยะของคุณเอง (Teachable Machine)

AI พื้นฐานของน้องตาวิเศษ (COCO-SSD) รู้จักของทั่วไปแค่ 80 อย่าง และไม่รู้จักบรรจุภัณฑ์ไทยเลย
วิธีที่ทำให้แม่นขึ้นมากที่สุดคือเทรนโมเดลจากรูปขยะจริง ถ่ายที่หน้าถังจริง ด้วยกล้องตัวที่ใช้จริง
ใช้เวลาประมาณ 1 ชั่วโมง และไม่ต้องเขียนโค้ด

## 1. วางแผนหมวด (class)

ตั้งชื่อหมวดให้**ขึ้นต้นด้วยชื่อถัง** แอปจะรู้เองว่าหมวดนั้นต้องทิ้งถังไหน
ส่วนชื่อหลังเครื่องหมาย `:` คือชื่อที่จะแสดงบนจอ

| ถัง | ตัวอย่างชื่อหมวด |
|---|---|
| ถังขวดพลาสติก | `ขวดพลาสติก: ขวดน้ำใส PET`, `plastic_bottle: ขวดนม HDPE` |
| ขยะรีไซเคิล | `รีไซเคิล: กระป๋อง`, `recyclable: กล่อง UHT`, `รีไซเคิล: ขวดแก้ว` |
| ขยะอันตราย | `อันตราย: ถ่านไฟฉาย`, `hazardous: สเปรย์` |
| ขยะทั่วไป | `ทั่วไป: ซองขนม`, `general: แก้วกาแฟเปื้อน` |
| เงิน (เตือนห้ามทิ้ง) | `เงิน: ธนบัตร` |
| **ไม่มีขยะ (สำคัญมาก)** | `background` |

คำที่แอปรู้จัก: `plastic_bottle` / `ขวดพลาสติก`, `recyclable` / `รีไซเคิล`, `hazardous` / `อันตราย`,
`general` / `ทั่วไป`, `money` / `เงิน` / `ธนบัตร`, และ `background` / `ไม่มีขยะ` / `พื้นหลัง`
ถ้าชื่อไม่มีคำเหล่านี้ แอปจะถือว่าเป็นขยะทั่วไป

**ต้องมีหมวด `background` เสมอ** ให้ถ่ายหน้าถังตอนที่ไม่มีใครยื่นอะไร ถ่ายตอนมีคนเดินผ่าน
และถ่ายตอนมีมือเปล่ายื่นเข้ามา ถ้าไม่มีหมวดนี้ AI จะพยายามทายเป็นขยะตลอดเวลา

แบ่งหมวดตาม "หน้าตา" ไม่ใช่ตามถังอย่างเดียว เช่น กระป๋องกับขวดแก้วอยู่ถังรีไซเคิลเหมือนกัน
แต่หน้าตาต่างกันมาก ควรแยกเป็น 2 หมวด แล้วตั้งชื่อขึ้นต้นด้วย `รีไซเคิล:` ทั้งคู่

## 2. ถ่ายรูป

- ประมาณ **100–200 รูปต่อหมวด** (Teachable Machine กดค้างปุ่ม Hold to Record แล้วได้หลายสิบรูปใน 2–3 วินาที)
- ถ่ายจาก**กล้องตัวที่ติดที่ตู้จริง** ในตำแหน่งจริง แสงจริง
- หมุนของหลายมุม ใกล้-ไกล บี้-ไม่บี้ มีฉลาก-ไม่มีฉลาก หลายยี่ห้อ
- ถ่ายหลายช่วงเวลา (เช้า กลางวัน เย็น) ถ้าตู้ตั้งในที่แสงเปลี่ยน
- ให้คนหลายคนถือ มือจะต่างกัน AI จะไม่ไปจำมือแทนขยะ
- จำนวนรูปแต่ละหมวดควรใกล้เคียงกัน

## 3. เทรน

1. เปิด <https://teachablemachine.withgoogle.com/train/image> แล้วเลือก **Standard image model**
2. สร้างหมวดตามข้อ 1 แล้วอัดรูปด้วย Webcam หรือ Upload รูปที่ถ่ายไว้
3. กด **Train Model** (ค่าเริ่มต้นใช้ได้ ถ้ายังไม่แม่นลองเพิ่ม Epochs เป็น 100)
4. ทดลองยื่นของจริงในช่อง Preview ด้านขวา ถ้าหมวดไหนสับสน ให้เพิ่มรูปหมวดนั้นแล้วเทรนใหม่

## 4. ใส่โมเดลเข้าแอป

มี 2 วิธี เลือกวิธีเดียวก็พอ

**วิธี ก. ลิงก์ (ง่ายสุด)**
1. ใน Teachable Machine กด **Export Model** → แท็บ **Tensorflow.js** → **Upload (shareable link)** → **Upload my model**
2. คัดลอกลิงก์ เช่น `https://teachablemachine.withgoogle.com/models/AbC123xyz/`
3. ในน้องตาวิเศษ กด **เทรนสินค้าไทย** → เปิด **โมเดลแยกขยะของคุณเอง** → วางลิงก์ → กด **ใช้โมเดลนี้**
   (ลิงก์จะถูกจำไว้ในเครื่องนั้น ถ้ามีหลายตู้ ให้เปิดเว็บด้วย `https://waste-5b576.web.app/?model=ลิงก์โมเดล` ได้เลย)

**วิธี ข. ใส่ไว้ในเว็บ (ทุกเครื่องได้โมเดลเดียวกันอัตโนมัติ)**
1. Export Model → Tensorflow.js → **Download** จะได้ไฟล์ zip ที่มี `model.json`, `metadata.json`, `weights.bin`
2. แตกไฟล์ใส่โฟลเดอร์ `model/` ใน repo นี้ แล้ว merge เข้า `main` เว็บจะ deploy ให้เอง

เมื่อโหลดสำเร็จ มุมบนจะขึ้นว่า **โมเดลขยะไทย ✓** และผลที่มาจากโมเดลนี้จะมีไอคอน 🎯

## 5. แอปตัดสินใจอย่างไร

1. **ภาพจำ** จากรูปที่สอนในสตูดิโอ และจากปุ่ม "ไม่ถูก" ถ้าตรงกันชัดเจนจะใช้อันนี้ก่อน (เป็นการแก้เฉพาะหน้างาน)
2. **โมเดลของคุณ** ถ้ามั่นใจตั้งแต่ 75% ขึ้นไป
3. **COCO-SSD** เป็นตัวสำรองสุดท้าย

ถ้าโมเดลของคุณมั่นใจว่าเป็น `background` แอปจะไม่สแกน เว้นแต่ COCO-SSD จะมั่นใจมาก

## 6. ปรับปรุงต่อเนื่อง

- ให้คนกด **ไม่ถูก** ทุกครั้งที่ AI ทายผิด ระบบจะเก็บรูปไว้และแก้ทันที
- ทุก 1–2 สัปดาห์ ถ่ายรูปของที่ AI มักทายผิดเพิ่ม แล้วเทรนโมเดลใหม่
- ดู "ผู้ใช้ยืนยันว่าถูก ..%" ใต้ผลการจำแนก เพื่อดูว่าโมเดลใหม่ดีขึ้นจริงไหม
